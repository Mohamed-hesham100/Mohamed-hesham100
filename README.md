<details>
<summary align="center">✨ <b>How the animated snake above comes alive (one-time setup)</b></summary>
<br/>

The snake animates your real contribution graph. Add this GitHub Actions workflow at `.github/workflows/snake.yml` in this same repo, then push once to generate it:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: Mohamed-hesham100
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Once the `output` branch exists, the snake image above will render automatically.
